## What a verdict means

- **DONE** - every `def` in the row's Ruby file set is PORTED (the port binds
  the behaviour), PORTED-INLINE (the port carries it at a call site and cites
  this row's Ruby source), NAMED-COLLAPSE (the port's own words say it carries
  the behaviour by a different mechanism) or SKIP (a private helper the pinned
  deck cannot reach). There is no `def` the port does not carry, so the port
  matches the pinned Ruby on this row's whole surface.
- **WORKING** - the row has at least one GAP: a `def` the port does not carry.
  The gap is named below, with the def, its Ruby file and line, and whether
  the port mentions the name at all.

A def is a GAP when the port neither binds it, nor carries it at a citing
call site, nor names a collapse of it - AND the pinned deck can reach it, or
it is PUBLIC. A public method the deck never calls is still API.
